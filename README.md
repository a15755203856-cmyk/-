# 珠宝首饰购小程序

面向珠宝首饰品类的微信电商小程序示例，包含首页、商品详情页、购物车、下单流程以及订单物流跟踪等核心体验，便于快速演示线上选购到下单的完整闭环。

## 功能结构

- **首页**：展示精选珠宝列表，提供搜索、分类筛选以及购物车快捷入口。
- **商品详情**：图文详情、规格参数、购买数量调节以及加入购物车动作。
- **购物车**：商品勾选、批量全选、数量增减、移除和结算能力。
- **确认订单**：填写收货地址、选择支付方式、查看结算清单并提交订单。
- **订单详情**：展示订单摘要、收货信息、商品列表以及模拟物流节点时间轴。

## 目录结构

```
app.js / app.json / app.wxss   # 小程序全局配置与样式
pages/
  index/                       # 首页与商品列表
  product/                     # 商品详情页
  cart/                        # 购物车页
  checkout/                    # 确认订单页
  order/                       # 订单详情与物流
 data/products.js              # 珠宝商品静态数据
 utils/time.js                 # 时间格式与物流时间线工具
```

## 使用说明

1. 将项目导入微信开发者工具，选择“微信小程序”项目类型。
2. 在工具中使用测试 AppID（或注册的正式 AppID）打开项目即可预览。
3. 首页挑选商品并加入购物车，进入购物车勾选商品后点击“去结算”。
4. 在确认订单页填写收货信息并选择支付方式，即可模拟下单并查看物流进度。

> 本示例未对接真实支付与物流接口，所有数据均在本地存储中模拟演示，适合作为原型或演示项目基础。
